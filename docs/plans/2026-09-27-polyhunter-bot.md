# План: polyhunter 2.0 — рейтинг «умных денег» и Telegram-бот

## Цель
1. Сделать оценку кошельков глубже: эмпирический Байес вместо сырых z, q-values вместо флага, рейтинг 0–100 и тиры S/A/B/C/D/F, специализация по категориям, «анти-умные» кошельки (сигнал «против»).
2. Живой радар по ленте сделок: ставка умного кошелька, «свежий кит» (новый кошелёк сразу ставит крупно на аутсайдера в новостях — типичный инсайдерский паттерн), кластер (несколько кошельков в одну сторону за 10 минут).
3. Красивый бот в Telegram (RU/EN по языку пользователя): /start, /top, /wallet, /market, /follow, /following, /radar, /alerts, /threshold, /stats, /about, /help.
4. Публикация: приватный репозиторий gougoweg-wq/polyhunter.

## Архитектура
- `polyhunter/classify.py` — категория рынка по названию и слагу.
- `polyhunter/scoring.py` — чистая статистика: Пуассон-биномиальный хвост, кластерный z, BH q-values, эмпирический Байес, рейтинг и тир.
- `polyhunter/radar.py` — чистые детекторы сигналов по сделкам.
- `polyhunter/render.py` — HTML-сообщения Telegram (экранирование, карточки, алерты).
- `polyhunter/i18n.py` — тексты RU/EN.
- `polyhunter/store.py` — SQLite: пользователи, подписки, рейтинг, алерты, увиденные сделки.
- `polyhunter/api.py` — асинхронный клиент data-api / clob / gamma.
- `bot/app.py` — aiogram 3: команды, инлайн-кнопки, фоновые циклы радара и пересчёта.
- `hunter.py` — CLI сбора данных (как было) + команда `score`, пишущая таблицу `scores`.
- `tests/` — pytest на все чистые модули.

## Стек
Python 3.14, aiogram 3.31, httpx 0.28, Pillow 12 (аватарка), pytest. Хранилище — SQLite `data/hunter.db`.

## Задачи (каждая: тест → красный → код → зелёный → коммит)
1. classify: спорт/крипто/новости, включая «halftime», «US Open», «vs.» — `tests/test_classify.py`.
2. scoring.bh_qvalues: монотонность, q ≥ p, известный пример — `tests/test_scoring.py`.
3. scoring.eb_shrink: при большой SE оценка сжимается к нулю, при малой почти не меняется; τ² ≥ 0.
4. scoring.smart_score и tier: +4 п.п. → ~88; отрицательный край → тир D/F; S требует q<0.05, ROI>0.
5. scoring.wallet_stats: удержанные до исхода позиции, кластерный z, ROI, специализация.
6. radar.fresh_whale / smart_bet / clusters — на синтетических сделках.
7. render: экранирование HTML, карточка кошелька содержит ссылку на профиль, алерт содержит рынок и цену.
8. store: подписки и пороги, дедупликация сделок.
9. bot/app.py: команды и фоновые циклы; ручная проверка в Telegram.
10. Аватарка (Pillow), регистрация в BotFather, setMyCommands / setMyDescription через Bot API.
11. README, .env.example, run_bot.sh; git push в приватный репозиторий.

## Проверка
`.venv/bin/python -m pytest -q` — все зелёные; бот отвечает на каждую команду в Telegram; радар присылает хотя бы один алерт на живой ленте.
